# 🚀 YouTube Clicker Game & Dashboard

Ứng dụng mô phỏng đếm lượt đăng ký YouTube trực tiếp và trò chơi Clicker tương tác, được xây dựng trên nền tảng React, Vite và Tailwind CSS.

## 🛠️ Công nghệ sử dụng

- **Frontend:** React 18, Vite
- **Styling:** Tailwind CSS, PostCSS
- **API:** Google YouTube Data API v3
- **Deployment:** Vercel
